# Aprende Shop 🧠🛍️

**Aprende Shop** es una plataforma web educativa que conecta a personas interesadas en aprender habilidades digitales y creativas con productos, recursos y cursos seleccionados.  
Nuestro propósito es **empoderar a través del conocimiento**, impulsando la autonomía y el acceso a herramientas que fomenten el crecimiento personal y profesional.

---

## 🚀 Objetivo del proyecto
Desarrollar una aplicación web funcional con enfoque **Full Stack**, aplicando buenas prácticas de desarrollo, diseño accesible y metodologías ágiles.

---

## 🛠️ Tecnologías utilizadas
- **Frontend:** HTML5, CSS3, JavaScript  
- **Diseño:** Figma + Principios de accesibilidad  
- **Control de versiones:** Git & GitHub  
- **Metodología:** Scrum + Trello para gestión de tareas  

---

## 🧩 Funcionalidades actuales
- Página informativa sobre **Aprende Shop** y su equipo.  
- Sección de productos destacados.  
- Base para futura integración con:
  - Carrito de compras.
  - Sistema de login y registro.
  - Gestión de contenido desde backend.

---

## 🌱 Estado del proyecto
Proyecto en desarrollo como parte del curso **Full Stack Java**.  
Se irá ampliando progresivamente con funcionalidades dinámicas e integraciones a backend (Amazon, API’s, etc.).
